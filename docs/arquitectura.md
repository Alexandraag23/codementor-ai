Arquitectura propuesta

Frontend:
Interfaz de usuario desarrollada para estudiantes.

Backend:
Servicios encargados de la lógica de negocio.

Comunicación:
Ambos servicios se comunicarán a través de una red Docker denominada codementor-network.

Objetivo:
Permitir la interacción entre los componentes de la aplicación dentro de un entorno de integración continua.
